📖 How to find / set your endpoint URL

Your endpoint URL is your own serverless function that reads Firestore and answers ?key=…&device=…. Pick one of these:

  1. Vercel (easiest, free 100k/mo) — vercel deploy a folder with api/check.js. URL becomes https://<your-app>.vercel.app/api/check
  2. Cloudflare Workers (free 100k/day) — wrangler deploy. URL becomes https://kuro-check.<you>.workers.dev
  3. Firebase Cloud Functions (already on this project) — firebase deploy --only functions. URL is https://<region>-vipemote-e492e.cloudfunctions.net/check
  4. Any VPS — run Node/PHP/Python on a public domain. URL is https://your-domain.com/api/check

After deploying, paste the URL into the field below and hit Save Endpoint. The full serverless function code is provided below the form — copy, deploy, and it works out of the box with your Firebase project.
